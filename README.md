Spotify UI Clone

Project ini adalah latihan untuk mengimplementasikan layouting modern menggunakan HTML, CSS, dan JavaScript.

Fitur
- Antarmuka mirip Spotify Desktop terbaru.
- Sidebar & Library yang bisa di-scroll.
- Kontrol musik interaktif (Play/Pause).
- Progress bar lagu yang berjalan secara otomatis.

Teknologi
- **HTML5** untuk struktur.
- **CSS3** (Flexbox & Grid) untuk desain.
- **JavaScript** untuk interaksi.
- **FontAwesome** untuk ikon.
